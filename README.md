# .github

Organization-wide files for [HamsterProjekt](https://github.com/HamsterProjekt),
a fork that revives and modernizes [Project Hamster](https://github.com/projecthamster/hamster).

- [`profile/README.md`](profile/README.md) is shown on the organization's
  front page. It explains that this is a fork, why it exists, and what it changes.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) is used by every repository in the
  organization that does not have its own.

Repositories can override any of these files by adding their own copy.
